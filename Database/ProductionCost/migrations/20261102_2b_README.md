## An toàn runtime (tóm tắt)

| Điểm | Cơ chế |
|------|--------|
| Exclusive fail không xóa CT | `v_write_started` trong create_voucher |
| validate/calculate | chỉ `sp_pc_engine_check` — không claim |
| create_voucher | claim → build → overwrite assert → delete+post |
| claim | `GET_LOCK` + UPDATE có điều kiện — **không** START/COMMIT |
| unlock | `p_EXPECTED_ENGINE` bắt buộc; BI≠GK |
| EXP 622/627 | RUN `CONFIRMED` + đối chiếu `ALLOCATION_COSTS` (sau REDUCTION) |
| NVL ΣQ=0 multi-TP | orphan `SPLIT_QTY_ZERO`, không chia đều |
