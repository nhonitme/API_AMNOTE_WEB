# Migration G-K 2B — DEV/TEST only

## Cảnh báo

- **CẤM** chạy trên production.
- Chỉ chạy khi đã xác nhận tên database DEV/TEST + backup.
- Không coi `Database/database.sql` là migration.
- Connection API hiện `FromGlobalData` — **không** tự execute DDL/DML từ agent khi chưa xác nhận DSN DEV.

## Thứ tự triển khai

```text
0. Backup DEV/TEST (mysqldump schema+data)
1. mysql -D <dev_db>  (cd vào thư mục migrations)
2. SOURCE 20261102_2b_00_install_dev.sql
   hoặc lần lượt:
     20261102_2b_01_tables.sql
     20261102_2b_02_sp_engine.sql
     20261102_2b_03_sp_nvl_basis.sql
     20261102_2b_04_sp_period_lock_cogs.sql
     20261102_2b_99_verify_readonly.sql
3. Deploy API build có CogsTransferRuleCode.ExpTo154Only (cùng PR/code)
4. Chạy kịch bản 20261102_2b_98_test_scenarios_dev.sql (bỏ comment từng khối)
```

## Rollback DEV

1. Ưu tiên restore từ backup.
2. Hoặc: `SOURCE 20261102_2b_rollback_dev.sql`  
   (khôi phục COGS B-I via `20261102_2b_rollback_cogs_bi_only.sql` + DROP bảng/SP G-K).
