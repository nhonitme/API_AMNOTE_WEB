# Migration G-K 2B — DEV/TEST only (final safety gate)

## Cảnh báo

- **CẤM** production.
- Allowlist **committed**: `20261102_2b_APPROVED_ENV.sql` (DB + host + ENV tag).
- Placeholder `<<SET_AFTER_DEV_APPROVAL>>` → preflight **luôn FAIL**.
- Preflight / guard: **0 DDL**. FAIL dùng `PREPARE` với SQL cố ý sai cú pháp để tạo **ERROR 1064**, yêu cầu `mysql --abort-source-on-error` và **không dùng `--force`**.
- Ưu tiên restore backup khi rollback toàn diện.

## Điền môi trường đã duyệt

Sửa `20261102_2b_APPROVED_ENV.sql`:

```sql
SET @GK_2B_APPROVED_DB := 'ten_db_dev';
SET @GK_2B_APPROVED_HOST := 'hostname_may_chu';
SET @GK_2B_APPROVED_ENV_TAG := 'DEV'; -- hoặc TEST
SET @GK_2B_APPROVED_HOST_CONTAINS := ''; -- hoặc substring host nếu cần
```

## Cài đặt

```powershell
cd ...\Database\ProductionCost\migrations
.\Invoke-Gk2bStaticCheck.ps1
# Sau khi APPROVED_ENV đã điền + backup:
.\Invoke-Gk2bInstall.ps1 -MysqlExe mysql -MysqlArgs @('-h','...','-u','...','-p...','ten_db_dev')
```

Hoặc:

```bash
mysql --abort-source-on-error ... ten_db_dev -e "SOURCE 20261102_2b_00_install_dev.sql"
```

Thứ tự: `preflight` → `01`…`04` → `99_verify`. Preflight FAIL → lỗi SQL 1064, `mysql` dừng SOURCE, không chạy DDL. Không chạy migration qua công cụ tự tiếp tục sau lỗi.

## Rollback

```bash
mysql --abort-source-on-error ... -e "SOURCE 20261102_2b_rollback_dev.sql"
```

Preflight trước mọi DROP. Inventory SELECT trước/sau. Prefer mysqldump restore.

## Transaction COGS

- `CreateSessionAsync` → `BeginTransaction`.
- `RunCogsCreateVoucherAndCompleteAsync`: create_voucher + step DONE cùng TX; lỗi → `Rollback`.
- SP handler **không** xóa CT khi lỗi.
- Hook DEV: `@GK_2B_FAIL_POINT='AFTER_DELETE'|'DURING_POST'` (T10/T11).
