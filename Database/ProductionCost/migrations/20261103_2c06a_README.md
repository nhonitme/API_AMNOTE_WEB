# G-K 2C-06A — History DDL + Write Repository (MySQL 5.6-safe)

## Index / độ dài

| Thành phần | Giá trị |
|------------|---------|
| `STABLE_KEY` | **VARCHAR(190)** — UNIQUE full với `COMPANY_CD` |
| utf8 bytes | `(20+190)*3 = 630 ≤ 767` — không cần `innodb_large_prefix` |
| Canonical dài | C# → `PC_HIST_H:{sha256}` (73 ký tự) — **không** prefix unique |
| `CONTENT_FINGERPRINT` | VARCHAR(64) — đọc/ghi thật |
| `OPERATION_ID` | VARCHAR(64) — UNIQUE `(COMPANY_CD, OPERATION_ID)` |

## Idempotency

- Cùng OpId + StableKey + fingerprint → Noop  
- Khác StableKey / fingerprint (hoặc Confirm thiếu fingerprint DB) → Conflict  
- Race 1062 → đọc lại hàng đã commit (kể cả CONTENT_FINGERPRINT)
